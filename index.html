Supported image formats

Image formats that are supported depends on your browser but in general all modern image formats should work fine. Animated banners are not yet supported and they will be converted to static one. Output images are in resolution 500x48 pixels (TeamSpeak 6 shows them at 11/12 size, so 48 px fill one 44 px row step) so optimal size for the input image is width 500px and height that can be divided evenly.
Choose, drag and drop, or paste (Ctrl+V) the image you would like to convert into channel banners.
Images are not uploaded to a server and all processing is done in the browser.

TeamSpeak 6 Channel Image Generator

Simple interactive tool for generating background images for channels in the TeamSpeak 6 client. Upload any image and it will be resized and split into multiple images that you can simply use as banners on your channels.
Contribute to the project on GitHub (bug reports are welcomed) ! Based on the original TeamSpeak 5 Channel Image Generator.
